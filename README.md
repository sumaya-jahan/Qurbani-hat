# Qurbani Hat

A modern Qurbani animal marketplace web application where users can browse, view details, and book animals online.

## Live Website

https://radiant-duckanoo-d1eb37.netlify.app

## GitHub Repository

https://github.com/sumaya-jahan/Qurbani-hat

## Features

- Firebase Authentication
- Email & Password Login/Register
- Google Login
- Private Routes
- Dynamic Navbar
- Animal Details Page
- Sort Animals By Price
- Update User Profile
- Responsive Design
- Custom 404 Page

## Technologies Used

- React
- React Router
- Firebase
- Tailwind CSS
- DaisyUI
- React Toastify
